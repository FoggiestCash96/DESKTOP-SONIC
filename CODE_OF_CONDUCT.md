# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in all project spaces: issues, pull requests, discussions and any community channels we run.

In short:

- Be welcoming and patient, especially with newcomers and first-time contributors.
- Critique work, not people. Keep feedback specific and kind.
- No harassment, insults, discrimination, or sharing other people's private information.
- Assume good faith.

## Reporting

If someone breaks these rules, contact the maintainer through the repository owner's [GitHub profile](https://github.com/FoggiestCash96). Reports are handled privately. Maintainers may remove content, or block people who keep violating the code of conduct.
